# NIDHI (National Integrated Digital Healthcare Identifier)
The proposed system NIDHI introduces a Unique Healthcare ID (UHID) for each individual, similar in concept to a national identifier but dedicated to healthcare. This ID links the user to a cloud-based medical record vault accessible through a web portal and chatbot.

Using the Healthcare ID, doctors can instantly access a patient’s historical lab reports and prescriptions (with consent), while AI and ML techniques assist in identifying health trends and symptom–lab correlations. The system is implemented using Google Cloud Platform (GCP) for secure and scalable deployment.
